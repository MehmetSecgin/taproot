# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is published at the URL above and is incorporated here by reference.

In short: be respectful, assume good faith, and focus on the work. Behavior that makes contributors feel unsafe or unwelcome is not tolerated.

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests, discussions, commit messages, code comments — and to any communication where someone is representing the project (including conference talks, social posts, and direct messages about project work).

## Reporting

Report a violation by emailing **mehmetascgn@gmail.com**. Reports are handled confidentially.

Include:
- What happened, and where (link to the issue, PR, message, etc.).
- Who was involved.
- Whether the incident is ongoing.
- Anything you want kept confidential when the project responds.

You should expect:
- An acknowledgement within 5 business days.
- A summary of any action taken (or a reasoned decision not to act) once the report is closed.

## Enforcement

The maintainer reviews reports and decides on the response, following the enforcement guidelines in the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines). Responses range from a private warning to a permanent ban from project spaces.

Maintainers who do not enforce the Code of Conduct in good faith may face the same consequences.
